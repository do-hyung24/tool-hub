# 제출 초안

## 문제정의
바이브코딩으로 개인이 자동화 봇/스크립트를 직접 만드는 사례가 늘고 있지만,
이걸 필요로 하는 다른 사람에게 넘길 직거래 창구가 없다. 기존 외주 플랫폼은
계약·수수료 구조가 무거워 소규모 개인거래에 안 맞고, 무엇보다 "이 코드가
안전한지" 구매자가 확인할 방법이 없다.

## 핵심 유저
(판매자) 바이브코딩으로 툴을 만들어 부수입을 얻고 싶은 개인 /
(구매자) 반복작업을 자동화해줄 저렴한 기성 스크립트가 필요한 개인·소상공인

## 차별점
수수료 없는 순수 직거래 + 등록 시 AI가 룰기반 정적분석 + 조건부
LLM 호출 하이브리드 방식으로 코드를 자동 스캔해 구매자가 신뢰하고 살 수
있게 하는 보안 검증 계층. 기존 오픈마켓·깃허브엔 없는 "거래 전 자동
보안검증".

## AI 활용방식
등록된 코드(zip/GitHub 링크)를 OWASP 기준 취약점 카테고리로
스캔. 결과는 판매자 본인에게만 비공개 표시, Medium 이상 발견 시 "구매자
고지 권장" 넛지. 판매자는 수정 후 재스캔하거나 자율 고지 문구를 달고
그대로 등록 가능.
